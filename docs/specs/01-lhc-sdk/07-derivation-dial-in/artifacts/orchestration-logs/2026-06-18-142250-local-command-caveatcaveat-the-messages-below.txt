  ⎿  lbuild-impl v0.4.0 - Build and verify stories from a spec pack

     WHAT THIS DOES
       Agent chooses next step; CLI runs it and returns envelope. It reads spec
     pack,
       checks readiness, builds stories, resumes paused sessions, verifies work,
       applies bounded fixes, and records artifacts.

     WHAT IT EXPECTS
       Spec pack generated by liminal-spec. Core files:
         - epic.md: what to build, with acceptance criteria and test conditions
         - tech-design.md: how to build and verify
         - stories/*.md: one bounded build unit per story

     BASIC PROCESS
       1. inspect      Read the pack without changing it.
       2. preflight    Check config, git state, gates, and provider readiness.
       3. orchestrate  Run story-orchestrate for the normal one-story execution
     path.
       4. recover      Use status/resume and primitive story commands only for
     lower-level recovery or diagnosis.
       5. verify       Review the final package, then run your story gate and
     acceptance steps.
       6. fix          Use quick-fix only for bounded lower-level follow-up
     fixes.
       7. closeout     Use epic-review, epic-fix, and epic-reverify to assess
     epic completion.

       Repeat steps 3-6 per story. Run fix only when batch prepared.

     SKILL DELIVERY
       skill        Read the CLI-delivered ls-impl orchestration skill in
     bounded
                    chunks. Start with: lbuild-impl skill ls-impl

     USAGE
       lbuild-impl <command> [options]
       lbuild-impl <command> --help

     CORE OPTIONS
       Most commands use:
         --spec-pack-root <path>   Path to the spec-pack directory.
         --json                   Print a parseable JSON envelope.

       Story commands need --story-id <story-id>. Run command help before
     mutating commands.

     COMMANDS
       inspect             Read-only spec-pack inspection. Best first command.
       preflight           Validate config, gates, git state, and provider
     readiness.

       story-orchestrate   Run, resume, validate, or inspect one durable
     story-lead attempt through the composed story-lead loop.
       story-implement     Lower-level initial implementation pass for one
     story.
       story-continue      Lower-level retained story implementation follow-up.
       story-self-review   Lower-level retained story self-review pass.
       story-verify        Lower-level start or continue story verification.

       quick-fix           Apply one bounded fix from task description.
       epic-review         Run fresh epic-level review.
       epic-reverify       Reverify epic status against prior review findings.
       epic-fix            Apply prepared epic fix batch.
       skill               Read CLI-delivered skill onboarding/docs.

     OUTPUT CONTRACT
       Use --json for agent automation. Every command returns an envelope.

       Check:
         status      Did the CLI/runtime succeed?
         outcome     What happened operationally: ready, completed, blocked,
     etc.
         errors      What needs attention if status/outcome is not successful.
         artifacts   Evidence files written under the spec pack.
         continuationHandle   Resume token when long-running work can continue.

       Do not treat status=ok as proof the requested implementation is complete.
       Read outcome, errors/warnings, artifacts, and continuationHandle.

       If outcome is blocked, read errors/warnings/artifacts, fix prerequisites
     or
       report the blocker, then rerun the appropriate command.

     SAFETY
       - inspect is read-only.
       - preflight checks readiness before implementation work.
       - implementation, verification, quick-fix, and fix commands may mutate
     the
         target codebase and write artifacts into the spec pack.
       - Expect a dirty git worktree after mutating commands.
       - Provider-backed commands may call paid/authenticated external CLIs.
       - Current provider binaries: claude, codex.

     EXAMPLES
       lbuild-impl inspect --spec-pack-root ./docs/spec-build/epics/my-epic
     --json
       lbuild-impl preflight --spec-pack-root ./docs/spec-build/epics/my-epic
     --json
       lbuild-impl story-orchestrate run --spec-pack-root
     ./docs/spec-build/epics/my-epic --story-id 00-foundation --json

     SUGGESTED AGENT START
       1. Run inspect --json.
       2. Read status, outcome, warnings, and artifacts.
       3. Run preflight --json.
       4. Choose the next command from the process above.
       5. Run lbuild-impl <command> --help before each new mutating command.

     MORE HELP
       lbuild-impl <command> --help
