## What happened?

On Anthropic models where `thinking.display` defaults to `"omitted"` (claude-fable-5, claude-sonnet-5, claude-opus-4-7+), thinking blocks come back with empty `thinking` text and the full encrypted reasoning in `signature`. pi stores these correctly, but when building the next request, `convertMessages` (packages/ai/src/api/anthropic-messages.ts) skips any thinking block with empty text before checking the signature:

```ts
if (block.thinking.trim().length === 0) continue;
```

So on these models the model never gets its prior thinking back — any turn, including mid tool-use loop. Nothing errors; reasoning continuity is just silently lost. Anthropic's docs say signed blocks must be echoed back and that these models keep prior thinking in context by default.

Docs: https://platform.claude.com/docs/en/build-with-claude/adaptive-thinking, https://platform.claude.com/docs/en/build-with-claude/extended-thinking

## Steps to reproduce

Direct against api.anthropic.com with a plain API key, no extensions (repro is at the pi-ai stream level). Sonnet 5 shows it.

1. Turn 1: prompt that triggers thinking + a tool call. Assembled assistant message has `thinking: ""`, `thinkingSignature` ~400 chars.
2. Turn 2: send assistant message + toolResult back; capture the outgoing request body:

```
0 user      [text]
1 assistant [text, tool_use]     <- thinking block dropped, signature discarded
2 user      [tool_result]
```

## Expected behavior

The thinking block echoed with its signature — extended-thinking docs: "the entire sequence of consecutive thinking blocks must match the outputs generated by the model during the original request."

Looks like the empty-text skip predates display-omitted (fits the #3936 aborted-stream case, content-without-signature). This is the inverse shape — signature-without-content — now the normal case, not a corruption. `redacted_thinking` is already passed back correctly.

Running a local patch in the meantime: https://github.com/leegmoore/pi/commit/1a44f939e653a35479a4b6cda63f174856615ded
