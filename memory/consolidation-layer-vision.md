Lee (2026-07-05): the offline batch repair lane (fixes-log item 32) is deliberately the first instance of a general pattern he has planned — offline/batch passes over transcripts that build higher memory layers: distilled lessons, emotional-intensity weighting, skill creation from repetition + emotional content, search-topic extraction weighted by repetition/intensity, and associations. Biological consolidation shape (salience-tagged offline replay).

**Why:** foundation must be solid first, and the foundation IS the first memory layer: intelligent natural forgetting (compaction/band gradient). Lee (2026-07-05): "you can't add a bunch of things to memory until you already have a well working natural forgetting layer" — without selection pressure from forgetting, accumulation is hoarding and salience means nothing. All the consolidation layers are just more derivation types over the same immutable record, so no new architecture — new passes plus output storage.

**How to apply:** when designing anything touching the record or derivation store, protect this future: the raw record (including unsmoothed emotional heat that smoothing attenuates in views) is the substrate these layers read. Never let a derivation overwrite record content. Batch outputs swap into served views only at rebuild boundaries (see item 32's constraint).
